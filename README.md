### 1. RealScan — AI-Powered Real Estate Investment Intelligence

**An AI-powered real estate analysis platform focused on Maharashtra property investments.**

- Integrates MahaRERA data to support property research and analysis.
- Evaluates investment opportunities using a six-dimensional scoring framework.
- Provides Buy, Hold, or Avoid assessments, ROI analysis, and AI-generated reports.

**Tech Stack:** Next.js · FastAPI · PostgreSQL · Redis · GPT-4o · MahaRERA APIs

### 3. VoxShield — AI-Powered Voice Cloning Attack Detection

**A cybersecurity project concept focused on identifying and preventing AI-generated voice impersonation attacks.**

- Designed around real-time audio analysis for telephone and VoIP scenarios.
- Uses short audio windows to support low-latency risk assessment.
- Defines risk-based responses such as allowing, reviewing, holding, or escalating suspicious calls.
- Targets impersonation scenarios involving financial transfers, OTPs, credentials, and sensitive information.
- Prioritizes privacy-conscious processing without retaining raw audio by default.

**Tech Stack:** Python · FastAPI · WebSockets · Kotlin · Jetpack Compose · ONNX Runtime

🔗 [View VoxShield on GitHub](https://github.com/RavikishanSingh/VoxShield)

### 4. Senexa — Modern Android Music Player

**An Android music player project focused on a modern interface and flexible music playback.**

- Built around Kotlin and modern Android UI development.
- Uses AndroidX Media3 / ExoPlayer for audio playback.
- Integrates MediaSession and foreground playback services.
- Explores online music discovery, synchronized lyrics, and local data persistence.
- Uses Room and SharedPreferences for application data and preferences.

**Tech Stack:** Kotlin · Jetpack Compose · Material Design 3 · Media3 · Retrofit · Room

🔗 [View Senexa on GitHub](https://github.com/RavikishanSingh/Senexa-music-player-)
